Usar com IA

Para que serve

Um assistente de IA pode lançar e consultar o seu moneyPilot por você. Em vez de abrir o app, você diz “lance R$ 50 no mercado hoje” e o assistente faz o lançamento.

O assistente usa o mesmo acesso que você: entra com o seu e-mail e a sua senha e só enxerga os seus dados.

Passo a passo

  1. Abra o seu assistente de IA (um que consiga fazer chamadas de API pela internet).
  2. Copie o texto abaixo e cole no assistente.
  3. Diga o que quer fazer, por exemplo: “lance R$ 50 no mercado hoje”. Informe o e-mail e a senha quando ele pedir.
  4. Confira o resultado em Lançamentos.

Dúvidas comuns

É seguro passar a minha senha para o assistente?

A senha vale como o seu acesso. Use só um assistente em que você confia e peça que ele não a escreva em mensagens ou arquivos. Se tiver dúvida, troque a senha depois, em Perfil e segurança.

Minha conta é só do Google e não tem senha.

Para a API é preciso ter senha. Crie uma em Perfil → Criar senha.

O assistente errou um lançamento.

Corrija em Lançamentos. Peça sempre que ele confirme com você antes de apagar qualquer coisa.

Para desenvolvedores

O assistente usa a API REST do moneyPilot. Se você quer chamá-la por conta própria, estes são os passos. O contrato completo está no Swagger (interativo) e no OpenAPI (JSON).

1. Entrar

Peça o refresh token no corpo com refreshTokenInBody. No navegador isso não é necessário: lá o token fica num cookie protegido.

POST https://seu-endereco.exemplo/api/v1/auth/login
{ "email": "voce@exemplo.com", "password": "sua senha", "refreshTokenInBody": true }

→ { "token": "...", "refreshToken": "...", "expiresIn": 900 }

Mande o token em cada chamada: Authorization: Bearer <token>.

2. Renovar

O access token dura poucos minutos (expiresIn, em segundos). Ao receber 401, ou perto do fim, troque o refresh token por um novo par. O antigo deixa de valer, então guarde sempre o último.

POST https://seu-endereco.exemplo/api/v1/auth/refresh
{ "refreshToken": "..." }

→ { "token": "...", "refreshToken": "...", "expiresIn": 900 }

Reusar um refresh token já trocado encerra todas as suas sessões.

3. Listar contas e categorias

Pegue os ids para o lançamento.

GET https://seu-endereco.exemplo/api/v1/accounts
GET https://seu-endereco.exemplo/api/v1/categories

4. Lançar uma despesa

Dinheiro é número com 2 casas e ponto decimal (50.00); com vírgula ou mais de 2 casas a API responde 400 com o campo errado. Datas são aaaa-mm-dd.

POST https://seu-endereco.exemplo/api/v1/transactions
{ "accountId": 1, "categoryId": 3, "amount": 50.00, "type": "EXPENSE", "description": "Mercado", "date": "2026-10-28" }

5. Sair

POST https://seu-endereco.exemplo/api/v1/auth/logout
{ "refreshToken": "..." }

Cuidados

  • Guarde o refresh token como se fosse a sua senha: ele vale 30 dias, até você sair (o logout o revoga).
  • Conta criada só com o Google não tem senha. Para usar a API, crie uma em Perfil → Criar senha.
  • Trocar a senha no app encerra as sessões da API: entre de novo depois.
