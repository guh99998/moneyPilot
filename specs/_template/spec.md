# NNN — Título da feature

**Status:** rascunho
**Branch:** feature/NNN-nome-curto

## Problema

Qual dor do usuário isto resolve? Como ele lida com isso hoje?

## Objetivo

O que muda para o usuário quando estiver pronto, em uma ou duas frases.

## Regras de negócio

- Regras de valores, datas, status, arredondamento, permissões.
- Tudo que o Claude não deve decidir sozinho.

## Critérios de aceite

- [ ] **CA1** — Dado ..., quando ..., então ...
- [ ] **CA2** — Dado ..., quando ..., então ...

## Casos de borda

- Dados que já existem em produção
- Valores zero, negativos, limites
- Datas (fim de mês, fuso, passado/futuro)
- Outro usuário tentando acessar

## Fora de escopo

- O que **não** será feito agora, mesmo que pareça natural.

## Perguntas em aberto

- Dúvidas que precisam de resposta antes da aprovação.
